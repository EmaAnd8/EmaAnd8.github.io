ML-based fraud detection for public transport

M.Sc. thesis

A machine learning pipeline for detecting forged and fraudulent tickets across two datasets (validation and sold tickets). Covers anomaly detection, threshold calibration across cross-validation and full-data models, and a split-abuse detection pipeline for season passes.

RLC language server

Open-source contribution

Improved the LSP tooling of the RLC language in C++/MLIR, supervised by the author. Implemented scope-aware code completion, completion ranking via sortText, document symbols (Outline / Go to Symbol), and a configurable stdlib path. Built a coverage-guided fuzzer with libFuzzer to exercise the LSP server.
